# Liens Cardmarket à vérifier

Liste des extensions pour lesquelles le nom ou la forme de l'adresse Cardmarket est incertain (le nom anglais vient de TCGdex ; Cardmarket peut écrire autrement). Pour chaque extension : une carte d'exemple et l'adresse que l'application construirait. Cliquez, et si la fiche est introuvable, envoyez l'adresse correcte : une seule suffit par extension.

Sûres (adresses fournies par l'utilisateur) : `30th-Celebration`, `Aquapolis`, `EX-Unseen-Forces`.
